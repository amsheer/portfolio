# Amsheer S Portfolio

A simple, shareable online resume, ready for GitHub Pages.

## Run locally

Open `index.html` in a browser, or use any local static-server extension.

## Publish with GitHub Pages

1. Push the contents of this folder to the `branch-portfolio` branch of `https://github.com/amsheer/portfolio.git`.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, then choose `branch-portfolio` and `/ (root)`.
5. Save. GitHub will show the live address after deployment.

GitHub will show the live address after deployment. A project site normally uses an address such as `https://amsheer.github.io/portfolio/`.

## Adding content later

- Add project cards inside the `#projects` section in `index.html`.
- Replace the blog placeholder with article cards or link a future `blog.html` page.
- Place project images under `assets/images/` and reference them in the project cards.
- Keep the downloaded résumé in `assets/resume/` and replace it whenever it is updated.
